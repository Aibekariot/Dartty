# Dartty

Маскот-компаньон для рабочего стола Windows на чистом Dart: тёмный маг-звездочёт в капюшоне. Живёт поверх всех окон, гуляет по панели задач вперевалку, садится на края окон, реагирует на работу, напоминает про воду и сон, ведёт помодоро и иногда зовёт на бой с Багом.

Один `Dartty.exe` без консоли, без пакетов: только Dart SDK и собственные FFI-привязки к Win32.

## Сборка

Нужен Dart SDK 3.8+ (подойдёт тот, что идёт с Flutter).

```bat
build.bat
```

Скрипт по шагам: встраивает картинки (`tool/embed_assets.dart` → `lib/src/assets_data.dart`), запускает `dart analyze`, собирает `dart compile exe`, проверяет exe (`--selfcheck`) и переключает его в оконный режим (`tool/patch_subsystem.dart`). Результат: `build\Dartty.exe`. Если установлен `rcedit`, ставится иконка exe; если он испортит файл, остаётся версия без иконки.

Перед `dart analyze` вручную сначала запустите `dart run tool/embed_assets.dart`: сгенерированный файл не хранится в git.

## Проверка без Windows

```bash
dart run tool/sim.dart            # все сценарии
dart run tool/sim.dart walk jump  # выборочно
dart run tool/sim.dart --snaps    # плюс снимки кадров в build/snaps/
```

Симуляция гоняет «мозг» на фальшивом рабочем столе 1920×1080: появление и приветствие, перетаскивание и посадка на окно, езда вместе с окном, падение, бой с Багом (победа и проигрыш), помодоро, совет дня, ходьба с разгоном и торможением, прыжок на окно, моргание, кроссфейд, стоимость кадра в покое и 6 часов жизни без выхода за экран.

## Ключи запуска

| Ключ | Что делает |
|---|---|
| `--selfcheck` | читает картинки, рисует кадр без окон и выходит (код 0 — всё хорошо) |
| `--stats` | раз в 10 с пишет в журнал время кадра, число перерисовок и позы |
| `--no-autostart` | не трогать автозапуск в реестре при старте (удобно для тестов) |

Журнал: `%APPDATA%\Dartty\dartty.log`. Настройки: `%APPDATA%\Dartty\settings.json`, ключи те же, что у Go-версии, поэтому опыт и уровень сохраняются.

## Как устроено

```
bin/dartty.dart            точка входа
lib/src/app.dart           мозг: состояние, физика, эмоции, таймеры (без Win32)
lib/src/anim.dart          пружины, кроссфейд, походка, моргание, дыхание, плащ
lib/src/gfx.dart           картинки premultiplied BGRA, ресайз, аффинное рисование, облачко
lib/src/png.dart           мини-декодер и кодер PNG через ZLibCodec
lib/src/content.dart       реплики, советы, титулы, списки программ
lib/src/settings.dart      настройки и уровни
lib/src/world.dart         интерфейс World: всё, что мозгу нужно от системы
lib/src/win/               FFI-привязки, World для Windows, окна, трей, меню, фоновый изолят
tool/                      embed_assets, patch_subsystem, sim
```

**Почему цикл сообщений синхронный.** Окна Win32 получают сообщения только в потоке, который их создал. Dart VM после `await` может продолжить изолят на другом потоке ОС из своего пула: под нагрузкой (изоляты, HTTP, сборка мусора) это воспроизводится. Поэтому GUI крутит цикл `PeekMessageW` → кадр → `MsgWaitForMultipleObjectsEx` до следующего кадра и никогда не отдаёт управление event loop. В модальных циклах Windows (меню трея) кадры идут по `WM_TIMER`.

**Где асинхронность.** Всё асинхронное (будущий разговор с локальным ИИ через `HttpClient`) живёт в фоновом изоляте `lib/src/win/worker.dart` со своим event loop. GUI отправляет ему задачу через `SendPort`, ответ приходит в скрытое окно через `PostMessageW`. При старте мост проверяется запросом `ping`, ответ виден в журнале.

## Анимация

- 60 кадров в секунду, координаты дробные: окно двигается на целые пиксели, дробная часть дорисовывается внутри холста билинейно.
- Походка вперевалку: тело `walk_body` и две копии лапки. Фаза шага растёт с пройденным путём, тело покачивается вокруг точки между лапками и подпрыгивает дважды за цикл. Перед ходьбой Dartty поворачивается боком, разгоняется и тормозит за 0,25 с.
- Смена позы: кроссфейд 150 мс с пружинкой по масштабу. Масштаб, наклон и подскок тянутся к цели пружинами, приземление сжимает до 0,8 с отскоком.
- Моргание каждые 3–6 с (иногда двойное), дыхание ±1%, колыхание нижней трети плаща, наклон к курсору в позе `curious`.
- Перерисовка только при изменении параметров: в покое около 13 кадров в секунду из 60.
